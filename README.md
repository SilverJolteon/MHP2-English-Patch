# Monster Hunter Portable 2nd - English Translation Patch

<img src="/assets/Example.png" width="480px"/>

This is a work-in-progress port of the English text from Freedom 2 to Portable 2nd.
<br/><br/>
<b>No AI was used in the making of this patch.</b>

## Usage
Apply the [ISO patch](/latest_build) with either [DeltaPatcher](https://www.romhacking.net/utilities/704/) (PC) or [UniPatcher](https://play.google.com/store/apps/details?id=org.emunix.unipatcher&pcampaignid=web_share) (Android) to a clean copy of Monster Hunter Portable 2nd (ULJM05156).
